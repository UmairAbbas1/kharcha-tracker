% ── Phase 4 features ──────────────────────────────────────────────────────────
\section{Phase 4 — Features to Build Next}

Each item below is implementable within the current stack using free-tier APIs.
Priority is ordered by user impact vs.\ engineering effort.

% ── 4.1
\begin{featurebox}{4.1 \quad Voice Expense Entry \textnormal{\small — Groq Whisper, 1 day}}
\textbf{What:} User taps a microphone button and says
``Spent 450 on biryani today at Burns Road.''
The app transcribes with Groq Whisper (\texttt{whisper-large-v3-turbo}),
extracts amount/category/vendor/date via the same LLM pipeline as OCR,
and pre-fills the form.

\textbf{Why USP:} No competitor in the Pakistani market offers voice-to-expense
in Urdu and English. Groq Whisper supports both languages.

\textbf{How:} New \texttt{POST /api/scan-voice} endpoint accepts a
\texttt{audio/webm} blob. Groq transcription → same JSON extraction prompt
already used in \texttt{receiptScanner.js}. Frontend uses
\texttt{MediaRecorder} API (no library needed).

\textbf{Free tier:} Groq Whisper — currently no stated request limit.
\end{featurebox}

\vspace{6pt}

% ── 4.2
\begin{featurebox}{4.2 \quad Monthly AI Spending Summary \textnormal{\small — Groq + Resend + cron, 1 day}}
\textbf{What:} On the 1st of every month, each workspace owner receives an
email with a plain-language summary:
\emph{``You spent Rs\,42,000 in June. Food was your biggest category (38\%).
Transport is up 22\% vs.\ May. You stayed within budget 4 out of 5 categories.''}

\textbf{Why USP:} Generic trackers show charts. Kharcha Tracker tells you
what it means — in one paragraph, in your language.

\textbf{How:}
\begin{itemize}[leftmargin=1cm, topsep=2pt]
  \item \texttt{cron-job.org} (free) calls \texttt{POST /api/monthly-summary} on the 1st at 9 AM PKT.
  \item Backend aggregates last month's expenses per category, computes MoM change.
  \item Groq \texttt{llama-3.3-70b-versatile} generates the summary paragraph.
  \item Resend delivers the email with the existing HTML template engine.
\end{itemize}

\textbf{Free tier:} Groq text — 14,400 requests/day. Resend — 3,000 emails/month.
\end{featurebox}

\vspace{6pt}

% ── 4.3
\begin{featurebox}{4.3 \quad CSV / Excel Export \textnormal{\small — No new dependency, 2 hours}}
\textbf{What:} A single ``Export'' button on the dashboard downloads the
current month's expenses as a \texttt{.csv} file.
Optional: full history as \texttt{.xlsx} via SheetJS.

\textbf{Why USP:} Every accountant and every household manager in Pakistan
uses Excel. This is a basic trust signal that the app takes data seriously.

\textbf{How:} \texttt{GET /api/export?workspace\_id=\&month=\&format=csv}
— streams a CSV with headers: Date, Title, Category, Amount (PKR).
No new npm package for CSV. SheetJS (\texttt{xlsx}) for Excel if needed.
\end{featurebox}

\vspace{6pt}

% ── 4.4
\begin{featurebox}{4.4 \quad Bank SMS Auto-Parsing \textnormal{\small — Regex + LLM, 2 days}}
\textbf{What:} Pakistani banks (HBL, MCB, UBL, Meezan Bank, Easypaisa, JazzCash)
send structured transaction SMS messages. The user pastes or forwards an SMS
into the app. The system parses it into a draft expense automatically.

Sample SMS: \texttt{``MCB: Rs.2,500 debited from A/C **1234 at KFC DHA on
07-Jul-26. Avl Bal: Rs.18,750''}

Extracted: \{amount: 2500, vendor: ``KFC DHA'', category: ``Food'', date: ``2026-07-07''\}

\textbf{Why USP:} This is the single most-requested feature by Pakistani users
of any money management app. No existing free-tier tracker solves it.

\textbf{How:}
\begin{itemize}[leftmargin=1cm, topsep=2pt]
  \item \texttt{POST /api/scan-sms} accepts raw SMS text (no image, no audio).
  \item Bank-specific regex patterns extract structured fields where possible.
  \item Fallback: same Groq LLM prompt as OCR for unrecognised formats.
  \item No new SDK required — reuses existing Groq client.
\end{itemize}

\textbf{Free tier:} No additional cost. Reuses Groq quota.
\end{featurebox}

\vspace{6pt}

% ── 4.5
\begin{featurebox}{4.5 \quad Google Stitch UI Refresh \textnormal{\small — Design tool, 1 day}}
\textbf{What:} Use Google Stitch (\href{https://stitch.withgoogle.com}{stitch.withgoogle.com})
to generate a polished, production-quality UI for the dashboard, add-expense
form, and onboarding screens. Stitch exports clean HTML/CSS and integrates
with Kiro via its MCP server.

\textbf{Why:} Stitch is Google's AI UI design tool (launched I/O 2025, updated
March 2026). It generates multi-screen Figma-exportable designs from a text
prompt in under a minute.
It connects to Kiro via \textbf{Model Context Protocol (MCP)}, meaning designs
can flow directly into the codebase without manual copy-paste.

\textbf{How to use with Kiro:}
\begin{enumerate}[leftmargin=1cm, topsep=2pt]
  \item Visit \url{https://stitch.withgoogle.com} — free, no account required.
  \item Prompt: \emph{``Pakistani expense tracker app, royal blue \#4169E1 and
        powder pink \#F7A8C4, mobile-first, glassmorphism cards, PKR currency,
        dark-mode compatible.''}
  \item Export HTML/CSS or connect the Stitch MCP server in
        \texttt{.kiro/settings/mcp.json}.
  \item Kiro reads the design via MCP and implements it directly into React components.
\end{enumerate}

\textbf{Kiro MCP config (add to \texttt{.kiro/settings/mcp.json}):}
\begin{verbatim}
{
  "mcpServers": {
    "stitch": {
      "command": "npx",
      "args": ["@google/stitch-mcp@latest"],
      "disabled": false
    }
  }
}
\end{verbatim}
\end{featurebox}

\vspace{6pt}

% ── 4.6
\begin{featurebox}{4.6 \quad OCR Provider Abstraction \textnormal{\small — Reliability, 2 hours}}
\textbf{What:} Wrap the Groq vision call behind an \texttt{OcrProvider}
interface. Implement a \texttt{GeminiProvider} fallback.
Active provider selected via \texttt{OCR\_PROVIDER=groq|gemini} env variable.

\textbf{Why:} Groq deprecated one vision model during active development of
Phase 3. An abstraction ensures a model change is a one-line env variable
update, not a code change.

\textbf{How:}
\texttt{backend/ocr/providers/GroqProvider.js} and
\texttt{backend/ocr/providers/GeminiProvider.js},
each exporting \texttt{async scan(dataUri, categories)}.
\texttt{receiptScanner.js} imports the active provider at startup.
\end{featurebox}

\section*{Conclusion}

Kharcha Tracker is positioned to be Pakistan's first AI-native expense tracker.
The combination of features that competitors charge for (OCR, team workspaces)
being free from day one, with features that competitors do not offer at any price
(WhatsApp alerts, Urdu voice entry, bank SMS parsing), creates a defensible
market position. Phase 4 can be implemented entirely within the existing
free-tier stack, with no infrastructure cost, in approximately six working days.
